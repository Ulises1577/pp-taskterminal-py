TaskTUI 

¡Hola! Este es un gestor de tareas simple y con interfaz de terminal. Es un proyecto personal, seguro a medida que lo vaya ocupando ire corrigiendo algunos errores o sumando funciones.

Este proyecto nacio intentando recordar funciones basicas y tratar en lo posible de usar lo menos posible la IA o al menos ocuparla para recordar sintaxis o correcion de errores. 

Espero te guste, veremos como le va. 

Caracteristicas: 
- Ordenamiento por prioridad: Use un Bubble Sort por que es sencillo y no creo que tengas mas 100 tareas pendientes.
- Persistencia: Lo guarad en un .txt y en cada operacion actualiza dicho archivo. 
- Interfaz TUI: Contruido con la libreria 'rich' (en esta si necesite de la IA, primera vez usando esta libreria :0 )

Para su funcionamiento hice lo siguiente: 

1- Instalación de Rich: sudo pacman -S python-rich

2- Crear el alias "taskt" en ~/.bashrc:

3- Ejecutar task desde la terminal y yapo chango.
